Detailed Description

template<log::cpt::logger t_logger, typename t_data>
requires std::move_constructible<t_data> && std::copy_constructible<t_data> && ostream::cpt::has_output_operator<t_data>
class tnct::container::dat::circular_queue< t_logger, t_data >

Implements a circular queue which size is increased if it becomes full.

The purpose is to avoid unnecessary memory allocations to create nodes in the queue by reusing nodes which data have been read
