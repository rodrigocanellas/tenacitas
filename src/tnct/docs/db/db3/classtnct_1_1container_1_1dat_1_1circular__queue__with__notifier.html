requires std::move_constructible<t_data> && std::copy_constructible<t_data> && std::is_default_constructible_v<t_data> && ostream::cpt::has_output_operator<t_data>
class tnct::container::dat::circular_queue_with_notifier< t_logger, t_data, t_initial_size, t_incremental_size >

Implements a circular queue which size is increased if it becomes full, and notifies at every inclusion.

The purpose is to avoid unnecessary memory allocations to create nodes in the queue by reusing nodes which data have been read
